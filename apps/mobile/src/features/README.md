# Features

Каждая папка здесь — самостоятельная функция приложения.

```
features/<feature>/
  screens/     экраны (подключаются в src/app как маршруты)
  components/  UI, используемый только внутри фичи
  hooks/       состояние и логика представления
  services/    обращения к API через src/shared/api
  state/       минимальное состояние фичи (context), если оно нужно нескольким экранам
  types/       типы фичи (общие доменные типы берутся из @foodlens/core)
  index.ts     публичный API фичи
```

Правила:

- Подпапки создаются только когда в них появляется код.
- Снаружи фича импортируется только через `index.ts`, без глубоких импортов.
- Фича может использовать другую только через её `index.ts`, без циклов.
  Сейчас так `onboarding` переиспользует поля формы и сохранение из `profile`.
  Независимые фичи друг о друге не знают: `meal-plan` ничего не знает о `scan`.
- Общее для всех — в `@foodlens/core` (модели, validation) или `src/shared` (UI, API client).
- UI не обращается к AI-провайдерам: только к своему API через `services/`.
- Включение и выключение фичи — через feature flags (`src/shared/feature-flags`),
  маршрут защищается в `src/app`, код фичи при этом не трогается.
